# Веломаршрути Звягеля

Інтерактивна карта велосипедних маршрутів і туристичних місць Звягеля. Це один файл `index.html` без збірки й серверної частини, тому його можна розмістити на GitHub Pages.

## Що вміє сайт

- Показує маршрути й туристичні точки на карті OpenStreetMap.
- Має режим редагування: створення, зміна й видалення маршрутів та точок.
- Рахує довжину маршруту в кілометрах.
- Імпортує й експортує маршрути у форматі GPX.
- Зберігає резервну копію всіх даних у файл JSON і відновлює з неї.
- Показує місце користувача на карті.

## Файли

| Файл | Призначення |
|------|-------------|
| `index.html` | Весь сайт: розмітка, стилі й код |
| `data.json` | Необов’язковий. Дані маршрутів і точок для всіх відвідувачів |
| `README.md` | Ця інструкція |

## Публікація на GitHub Pages

1. Створіть публічний репозиторій на github.com.
2. Завантажте `index.html` (**Add file → Upload files → Commit changes**).
3. Відкрийте **Settings → Pages**, у розділі **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`, натисніть **Save**.
4. Через 1–2 хвилини сайт буде за адресою `https://ВАШ-НІК.github.io/НАЗВА-РЕПОЗИТОРІЮ/`.

## Як змінити маршрути

1. Відкрийте сайт і ввімкніть **Режим редагування** угорі.
2. Внесіть зміни:
   - **Новий маршрут.** Натисніть «+ Новий» і клікайте по карті, щоб додавати точки. Коли закінчите, натисніть «Готово».
   - **Змінити лінію.** Натисніть цю кнопку біля маршруту. Тягніть білі кружечки, щоб перемістити точку. Клік по лінії вставляє нову точку. Правий або подвійний клік по кружечку видаляє її.
   - **Параметри.** Назва, колір, складність, опис і зміна напрямку.
   - **Нова точка.** Натисніть «+ Додати» й клікніть на карті. Існуючі точки можна тягнути, а в спливному вікні — редагувати чи видаляти.
   - **GPX.** «Імпорт GPX» додає трек з телефона чи навігатора як новий маршрут, кнопка GPX біля маршруту його експортує.
3. Натисніть **Зберегти копію (JSON)**.
4. Перейменуйте завантажений файл на `data.json`.
5. У репозиторії натисніть **Add file → Upload files**, завантажте `data.json` і **Commit changes**. Через хвилину зміни побачать усі відвідувачі.

## Звідки сайт бере дані

Порядок пріоритету:

1. Зміни, збережені в браузері (тільки у того, хто редагував).
2. Файл `data.json` у репозиторії.
3. Початкові дані, вбудовані в `index.html`.

Тому свої зміни ви бачите одразу, а відвідувачі лише після оновлення `data.json`. Щоб побачити сайт їхніми очима, відкрийте його в режимі інкогніто. Якщо після оновлення нічого не змінилося, натисніть Ctrl+F5.

## Хто може змінювати карту

Режим редагування не захищений паролем, але чужі зміни зберігаються тільки в браузері того, хто їх зробив. Публічні дані змінює той, хто має доступ до репозиторію. Щоб додати редакторів, відкрийте **Settings → Collaborators → Add people**.

## Чернетки

Маршрути з позначкою «чернетка» прокладені між точками навмання, а не по реальних дорогах. Їх потрібно перевірити на місцевості й виправити або замінити GPX-треком, записаним на велосипеді. Якщо слово «чернетка» більше не потрібне, видаліть у `data.json` рядок `"draft": true` у відповідному маршруті.

## Безпека

Карта не гарантує, що маршрут безпечний для велосипеда. Перед публікацією перевіряйте покриття, рух транспорту й доступність, а відвідувачам нагадуйте робити те саме.

## Обмеження

- Кнопка «Моє місце» працює тільки через HTTPS. GitHub Pages його забезпечує.
- Карта потребує інтернету: плитки OpenStreetMap і бібліотека Leaflet завантажуються з мережі.
- Резервну копію варто робити регулярно, бо дані в браузері можуть зникнути після очищення історії.
